↓ scroll — redimensionne la fenêtre pendant ou après l'animation

Le texte est découpé un écran avant d'arriver, puis animé ligne par ligne.

Ici aucune animation GSAP n'est renvoyée : une classe CSS pilote les mots via la variable --word. Après un redécoupage, les nouveaux mots prennent directement leur état final.

Avec replay, le split est conservé pour pouvoir rejouer l'animation à chaque passage.
